# Code of Conduct

## Our Commitment

Akeng.MauiCrashReporter is committed to providing a welcoming, inclusive,
respectful, and harassment-free environment for everyone participating in
the project.

We welcome contributions and participation from people of all backgrounds
and levels of experience.

## .NET Foundation Code of Conduct

Akeng.MauiCrashReporter follows the .NET Foundation Code of Conduct.

All contributors, maintainers, reviewers, issue reporters, and other
community participants are expected to follow it when participating in
project spaces.

The current .NET Foundation Code of Conduct can be found here :
https://dotnetfoundation.org/about/policies/code-of-conduct

## Expected Behavior

Participants are expected to:

- communicate respectfully and constructively;
- be considerate of different viewpoints and experiences;
- provide technical feedback without personal attacks;
- accept constructive feedback professionally;
- focus discussions on what is best for the project and its community;
- help create an environment where new contributors feel welcome;
- respect the privacy and safety of other community members.

## Unacceptable Behavior

Unacceptable behavior includes, but is not limited to:

- harassment or discrimination;
- personal attacks or insults;
- intimidation or threats;
- deliberately disruptive behavior;
- publishing another person's private information without permission;
- inappropriate sexual attention or content;
- sustained behavior that creates an unsafe or hostile environment.

## Scope

This Code of Conduct applies to all Akeng.MauiCrashReporter project spaces,
including:

- GitHub Issues;
- GitHub Pull Requests;
- GitHub Discussions;
- code reviews;
- project documentation;
- project-related communication channels;
- community events or discussions where someone is representing the project.

## Enforcement

Project maintainers are responsible for clarifying and enforcing acceptable
behavior within project-controlled spaces.

Maintainers may take appropriate action in response to behavior that violates
this Code of Conduct.

Actions may include:

- requesting that inappropriate behavior stop;
- removing or editing inappropriate content where platform capabilities allow;
- closing or locking discussions;
- temporarily restricting participation;
- permanently restricting participation in project-controlled spaces.

Enforcement decisions should be made fairly, consistently, and with respect
for the privacy of everyone involved.

## Reporting

If you experience or witness behavior that violates this Code of Conduct,
please report it privately to the project maintainers.

Reports should not be submitted as public GitHub Issues when doing so would
expose sensitive or personal information.

Reports will be reviewed as promptly and fairly as reasonably possible.
